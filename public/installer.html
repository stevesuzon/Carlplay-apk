COUTEAU SUISSE

📲 AVANT D’ALLER SUR LE SITE
Appuyez d’abord sur INSTALLATION iPHONE / ANDROID. Vous verrez le parcours en quelques étapes : renseigner Nom + Prénom + E-mail, confirmer l’e-mail, arriver sur Couteau Suisse puis ajouter l’application à votre écran d’accueil. Ensuite, fermez l’explication et appuyez sur ALLER SUR LE SITE.

COMMENT INSTALLER

🍎 iPhone / iPad

  1. Appuyez sur Aller sur le site puis renseignez Nom + Prénom + Adresse e-mail.
  2. Appuyez sur Confirmer mon adresse e-mail, ouvrez l’e-mail reçu et confirmez. Votre inscription est alors terminée : vous revenez automatiquement sur Couteau Suisse et ce formulaire ne sera plus redemandé.
  3. Dans Safari, appuyez sur Partager (le carré avec la flèche vers le haut).
  4. Appuyez sur Sur l’écran d’accueil.
  5. Appuyez sur Ajouter. L’icône Couteau Suisse apparaît sur votre écran d’accueil.

🤖 Android

  1. Appuyez sur Aller sur le site puis renseignez Nom + Prénom + Adresse e-mail.
  2. Appuyez sur Confirmer mon adresse e-mail, ouvrez l’e-mail reçu et confirmez. Votre inscription est alors terminée : vous revenez automatiquement sur Couteau Suisse et ce formulaire ne sera plus redemandé.
  3. Dans Chrome, appuyez sur le menu ⋮ en haut à droite.
  4. Appuyez sur Installer l’application ou Ajouter à l’écran d’accueil selon votre téléphone.
  5. Confirmez avec Installer ou Ajouter. L’icône Couteau Suisse apparaît sur votre écran d’accueil.
✅ Explication installation consultée. Vous pouvez maintenant aller sur le site.
