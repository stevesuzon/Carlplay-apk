Ajouter uniquement les pièces demandées si vous les avez

Seules les pièces indiquées ci-dessus apparaissent ici. Elles ne bloquent jamais le formulaire : si une pièce n’est pas demandée ou si elle n’est pas disponible, vous pouvez quand même préparer et envoyer l’e-mail. Si l’organisateur ne demande pas de photo d’identité, les boutons recto-verso ne sont pas affichés.

Message prérempli

Les pièces affichées proviennent des consignes trouvées pour cet événement. Si une consigne n’est pas suffisamment précise, l’application l’indique au lieu d’inventer une pièce à fournir.
Le bouton e-mail reste utilisable même si aucune pièce n’est ajoutée. Il ouvre le message déjà adressé à l’organisateur. Sur iPhone, vérifiez seulement les pièces réellement demandées puis appuyez sur Envoyer dans Mail.

🔒 Les pièces d’identité et documents ne sont pas stockés par cette page.
